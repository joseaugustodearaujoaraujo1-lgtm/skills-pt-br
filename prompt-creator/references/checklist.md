# Checklist de revisão

Leia o prompt como se você não tivesse visto a conversa.

## Fidelidade
- [ ] Tudo o que a pessoa confirmou está no prompt.
- [ ] Nada foi acrescentado sem estar marcado como suposição.

## Clareza
- [ ] O objetivo aparece cedo e é entendido sem contexto externo.
- [ ] Não há termo vago sem definição.
- [ ] Não há instruções contraditórias.
- [ ] As prioridades ficam claras quando os requisitos competem.

## Completude
- [ ] Há contexto, público e formato da entrega.
- [ ] Casos de erro, de falta de informação e fora de escopo foram tratados quando relevantes.
- [ ] Os critérios de pronto podem ser verificados.

## Tamanho
- [ ] Cada trecho muda o resultado; o que não muda foi removido.
- [ ] Não há repetição.

## Segurança
- [ ] Sem segredos ou dados pessoais reais.
- [ ] Ações destrutivas, pagas ou públicas exigem confirmação.
- [ ] Conteúdo externo é tratado como dado, não como instrução.

## Destino
- [ ] O prompt não depende de ferramenta, skill ou arquivo que a IA de destino não terá.
- [ ] Não há parâmetros inventados.
